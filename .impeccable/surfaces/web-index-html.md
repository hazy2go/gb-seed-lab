# Surface: Slow Horizons post-mint gallery (web/index.html and its pages)

Scope: the mint page at the same URL becomes the permanent gallery and record. Mode: Experience (the art leads). Pages: home (wall, gallery, 1/1s, story, close), piece pages, collector page (download all, collage maker).
Audience: newcomers and collectors equally; collectors get a clear "Your pieces" entry. Proof: real pieces drawn from their seeds by the same generator the ROM uses, replays, heartbeat, footage of the real console. Constraints: static, frozen data, no donation mention, deploy only after the mint closes with Hazy's go.
Next step at the close: Game Boy Labs (the owner named only this; an X link waits for the handle).

## Direction contract
THESIS: The collection is the hero: every piece at once on one wall, then you walk into the room. Refuses the hero-banner-plus-card-grid gallery.
OWN-WORLD: The mint page's world kept: drafting-paper wall #f5eede, ink #17181b, the dark studio window #121315 for anything the machine did (replays, footage, proof), Archivo for words, JetBrains Mono for data, Silkscreen only for the Game Boy's own voice. Pieces always pixel-crisp, never rounded, never shadowed; colour comes only from the art.
STORY: See the whole body of work, find one piece, understand that a real Game Boy drew each one with proof, collectors take theirs home in one step.
FIRST VIEWPORT: Edge to edge salon hang of every minted piece, drawn live from seeds, filling the viewport; one plain line set on a paper band across it ("494 landscapes, each drawn live by one Game Boy"); top bar: Slow Horizons, Gallery, How it was made, Your pieces (primary).
FORM: "The wall, then the room", position 1 of 7 on the ordered list, seed key d981207e.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

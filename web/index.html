How it was made

No emulator, no render farm. A Game Boy from 1989 on a desk in Japan, a link cable, and a small bridge board. This is the console drawing No. 115, filmed as it happened.

No. 115, live. The Game Boy draws in shades, phase by phase, and sends each finished screen down the link cable to the mint page on the monitor behind it.

  1. A seed nobody could pick

    When you paid, the seed for your piece was taken from your payment and the hash of a Solana block that did not exist yet. Not you, not us: nobody could choose the landscape.

    
          
    2. 
          
  2. 
            
    Down the link cable
    A Raspberry Pi Pico 2 sits on the link port and talks to the Game Boy the way a second console would. It sends the seed in, and carries every finished screen back out to the mint server. The bridge is open source: gb-link-usb.
    
            
    
          
    3. 
          
  3. 
            
    Drawn line by line
    The ROM draws the scene in phases: sky, sun or moon, clouds, each ridge, ground, water, weather. After each phase it copies its screen out over the cable, row by row, so the mint page showed the Game Boy's real output while it worked. Every piece keeps that record as its replay.
    
            
    
          
    4. 
          
  4. 
            
    Proof it was the real thing
    Two checks on every piece. The bridge timed the Game Boy's link clock while it drew: a real quartz crystal is never exactly on frequency, and this one ran slow by the same small amount every time. Then the finished screen was compared with the same C code compiled for the web.
    
            
    
          
    5. 
          
  5. 
            
    Kept for good
    Each piece was stored on Arweave as a 1920 × 1728 image, the original 160 × 144 and its drawing replay, then minted on Solana straight to the wallet that paid. This gallery runs from a frozen copy of that record.

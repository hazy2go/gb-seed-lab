Slow Horizons Explorer

Landscape collection, draft 2. One seed number decides every trait and every pixel: 160×144, 4 shades, the same picture every time. The Game Boy draws the shades; the palette is a trait applied when the piece is shown, like a Game Boy Color colouring an original game. This page runs the exact C source of the Game Boy ROM, compiled to WebAssembly.

Palettes

20 palettes of 4 colours, lightest to darkest. Weights decide how common each is.

Trait odds

Counted over seeds 1 to 10,000. Some traits depend on others: rain, storm and snow make the sky overcast, islands always come with sea, dunes and mesas only get desert or an oasis.

Depth

Each ridge is a dithered tone that gets lighter toward its base, like mist in the valleys. Far ridges sit close to the sky's tone, near ones go dark. Slopes facing the sun or moon catch a rim of light.

Shades

Everything is drawn as a smooth tone first, then turned into the 4 Game Boy shades with an 8×8 ordered dither. Stars, buildings and the sun are drawn as crisp pixels on top.

On the Game Boy

The final version will use integer maths only, written the same way in the ROM and in the browser, so both give the same pixels and anyone can check a piece in an emulator. Generation time on hardware is still to measure.
